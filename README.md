# Aurora Viewer Japanese — 非公式日本語化版

Aurora Viewerの非公式日本語化版です。

Second Life向けビューアー「Aurora Viewer」のユーザーインターフェースを日本語化しました。

## 日本語化について

- 翻訳項目数：11,739項目
- Windows x64向けビルド
- 日本語UIでの起動確認済み
- 翻訳ライブラリのテスト・コンパイルチェック済み

※試験公開版です。翻訳が不自然な箇所や、英語のまま残っている表示がある可能性があります。

## ダウンロード

GitHubの **Releases** から最新版をダウンロードしてください。

- `Aurora-Viewer-Japanese-Windows-x64.zip` — 日本語版ビューアー
- `Aurora-Viewer-Japanese-Source.zip` — 対応ソースコード
